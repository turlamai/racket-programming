# 写你自己的 lang——从内部 DSL 到一门独立语言

> 上一章我们用列表与解释函数定义了绘图指令。本章进一步控制模块语言和源文本的读取方式，亲手建立自己的 #lang。

## 先区分两件事

一门语言可以沿用 Racket 的括号写法，但改变允许使用的语法和模块行为。它也可以使用另一套文本格式，例如每行是一条绘图命令。

前者可以复用标准 Reader；后者需要定义自己的读取规则。拥有独立的 #lang 不一定意味着必须实现新的文本解析器。

## 第一步：定义模块语言

在空目录创建 hello.rkt：

```racket
#lang racket/base
(provide (rename-out [hello-module-begin #%module-begin]))

(define-syntax-rule (hello-module-begin body ...)
  (#%module-begin
   (displayln 'body) ...))
```

这个宏改变模块主体的行为：每个顶层形式都作为数据打印，而不是按普通 Racket 表达式执行。宏模板中的 displayln 与 #%module-begin 使用定义处的绑定。

在同一目录创建 demo.rkt：

```racket
#lang s-exp "hello.rkt"
你好
世界
(+ 1 2)
```

运行 racket demo.rkt，预期依次打印：

```text
你好
世界
(+ 1 2)
```

最后一行没有求和，因为 hello 的模块主体宏要求打印数据。这里的 hello 并不是任意纯文本语言；源文件仍需符合标准读取器的语法。

## 第二步：给语言一个名字

将 hello.rkt 的内容保存到如下目录的 main.rkt：

```text
hello/
  main.rkt
  lang/
    reader.rkt
```

reader.rkt 写成：

```racket
#lang s-exp syntax/module-reader
hello
```

这里 hello 指向集合 hello 的 main.rkt。进入 hello 的父目录执行：

```sh
raco pkg install --auto --link ./hello
```

在集合名没有冲突、安装成功的前提下，现在可以在其他目录创建 demo.rkt：

```racket
#lang hello
你好
世界
```

运行方式与之前相同。练习完成后，可用 raco pkg remove hello 移除本次练习安装的包（先确认没有同名的其他项目）。

## 第三步：自定义文本读取

现在创建另一个独立集合：

```text
literal/
  lang/
    reader.rkt
```

这次不使用默认的 S 表达式读取器。reader.rkt 内容如下：

```racket
#lang racket/base
(require racket/port)
(provide (rename-out [literal-read read]
                     [literal-read-syntax read-syntax]))

(define (literal-read-syntax src in)
  (define content (port->string in))
  (datum->syntax
   #f
   `(module literal racket/base
      (display ,content))))

(define (literal-read in)
  (syntax->datum (literal-read-syntax #f in)))
```

port->string 读取输入端口的全部剩余内容，不只读取一行。datum->syntax 构造模块语法对象，模块语言为 racket/base。用户的文本作为字符串嵌入 display 的参数，不作为 Racket 程序执行。

从 literal 的父目录执行 raco pkg install --auto --link ./literal。另建文件：

```text
#lang literal
第一行文字
第二行文字
```

用 racket 运行该文件，预期打印 Reader 收到的剩余文本。语言声明后的换行是否包含在剩余文本中取决于读取入口；本例不承诺复现整个文件的原始字节。

这只是教学 Reader：没有精确的源位置映射、编辑器语言信息或输入长度限制。真正的语言还需要错误诊断、资源限制和测试。

## 回顾三个阶段

Reader 将源文本转换成模块语法对象。Expander 在模块语言提供的规则下解析绑定、展开宏。运行时执行得到的程序。编译与模块实例化还有其他细节，本章先建立这个概念模型。

练习：修改 literal，让它将每一行转换成带行号的字符串，再作为数据嵌入模块。不要把文本直接拼接成可执行代码。
