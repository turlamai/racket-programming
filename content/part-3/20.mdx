# Lambda 演算——用函数表达一切计算

> λ 演算只有三种表达式——变量、函数抽象、函数应用——没有数字、没有 if、没有循环，却足以表达一切可计算的东西。

你写过函数，知道函数接收参数、返回结果。你也听过“函数式编程”，大概还背过闭包、高阶函数、递归这些词。但你有没有想过：把一门编程语言剥到最薄，最少还需要什么，它才能算东西？

1930 年代，数学家 Alonzo Church 给出了一个极端的答案：只要函数，就够了。他设计了一套叫 λ 演算（lambda calculus）的形式系统——没有数字、没有布尔、没有条件分支、没有循环，整个系统只有三种表达式。后来建立的等价性结果表明，这套极简的系统和图灵机一样强大，能表达一切可计算的函数。

这不是一段历史趣闻。**λ 演算提供了理解 Racket 函数的一种基础数学模型。** Racket 的 `lambda`、它的闭包、它“函数是一等公民”的设计，全部直接来自这套九十年前的数学。理解了 λ 演算，你就摸到了函数式编程的最底层。

这一讲先把基础打牢：λ 演算的语法、核心的 β 归约规则，以及怎么用它凭空造出布尔值和自然数。

## 整个系统只有三种形式

λ 演算里所有合法的项（term）只有三种：

- 变量：`x`
- 函数抽象（abstraction）：`λx. M`，参数是 `x`，函数体是 `M`
- 函数应用（application）：`M N`，把函数 `M` 应用到参数 `N`

就这三种，没有第四种。把它翻译成 Racket，你立刻就眼熟：

```text
; 变量
x

; 函数抽象：λx. M
(λ (x) M) ; λ 就是 lambda 的简写，两者完全等价
(lambda (x) M) ; 这一行和上一行没有任何区别

; 函数应用：M N
(M N) ; 函数和参数用括号包起来
```

Racket 允许你直接写 `λ` 这个字符——它在 Racket 里和 `lambda` 是同一个关键字。这不是巧合：Racket 的核心语法，几乎就是 λ 演算穿了件衣服。

注意 λ 演算的函数永远只吃一个参数，`(λ (x) M)` 对应 `λx. M`。那两个参数的函数怎么办？答案是再套一层——先用第一个参数返回一个新函数，再让它吃第二个：

```text
(λ (x) (λ (y) ...)) ; 依次接收 x、y，需分两次调用
```

这种把多参数拆成一串单参数的技巧叫柯里化（currying），是函数式编程的看家本领，也是 λ 演算天生就支持的写法。

## β 归约，唯一的求值规则

语法有了，怎么“运行”它？λ 演算只有一条求值规则，叫 β 归约（beta reduction）：

```text
(λx. M) N → M[x := N]
```

把函数体 `M` 中自由出现的 `x` 替换成参数 `N`，同时避免将参数中的自由变量意外捕获。一句话说就是“实参代入形参”。**整个 λ 演算的计算，就是反复做这一件事。**

看两个例子（第二个假设 A 中没有会被内层 y 捕获的自由变量）：

```text
(λx. x) y → y ; 最简单的函数：恒等函数，原样返回参数

(λx. λy. x) A B → (λy. A) B ; 先归约外层，把 x 换成 A
 → A ; 再归约，丢掉 B，返回 A
```

第二个例子里，`λx. λy. x` 接收 `x`，返回一个接收 `y` 但永远吐 `x` 的函数——它记住了第一个参数，无视第二个。这个函数你马上还会见到，它就是“真”。

用 Racket 跑一遍，行为完全一样：

```racket
((λ (x) x) 'y)
;; 'y

(define first-of (λ (x) (λ (y) x))) ; λx.λy.x
((first-of 'A) 'B)
;; 'A 返回 A，丢掉 B
```

## 用函数造出布尔和条件判断

λ 演算里没有布尔值。Church 给出了一个惊人的编码：把“真”和“假”都写成函数。

```text
TRUE := λt. λf. t ; 接收两个值，返回第一个
FALSE := λt. λf. f ; 接收两个值，返回第二个
```

`TRUE` 就是我们刚才那个“记住第一个、无视第二个”的函数。布尔值被编码成了“二选一”的行为。条件判断 `IF` 顺理成章——让布尔值自己去做选择：

```text
IF := λp. λa. λb. p a b

IF TRUE A B → TRUE A B → A
IF FALSE A B → FALSE A B → B
```

这些不是比喻，是能在 Racket 里直接跑的代码：

```racket
(define TRUE (λ (t) (λ (f) t)))
(define FALSE (λ (t) (λ (f) f)))
(define IF (λ (p) (λ (a) (λ (b) ((p a) b)))))

(((IF TRUE) 'yes) 'no)
;; 'yes

(((IF FALSE) 'yes) 'no)
;; 'no
```

代码里没有一个 `if` 关键字。不过 Racket 会先求值普通函数的实参，因此这里的 IF 只是选择已经求值的两个值；若要像 Racket 的 if 一样只执行一个分支，需要将分支包成无参数函数并在选择后调用。**布尔值自己就是一个会做选择的函数。** 这就是 Church 编码（Church encoding）的核心：不靠内建类型，靠函数的行为来“扮演”各种数据。

## Church 数，把数字变成应用次数

数字怎么办？Church 的办法是：数字 n，表示“把某个函数 f 连用 n 次”。

```text
0 := λf. λx. x ; f 用 0 次，原样返回 x
1 := λf. λx. f x ; f 用 1 次
2 := λf. λx. f (f x) ; f 用 2 次
3 := λf. λx. f (f (f x)) ; f 用 3 次
```

数字不再是“数量”，而是“应用次数”。验证一下：把 Church 数 3 作用到 `add1` 和 `0` 上，应该得到 3。

```racket
(define c0 (λ (f) (λ (x) x)))
(define c1 (λ (f) (λ (x) (f x))))
(define c2 (λ (f) (λ (x) (f (f x)))))
(define c3 (λ (f) (λ (x) (f (f (f x))))))

((c3 add1) 0)
;; 3 add1 连用 3 次：0 → 1 → 2 → 3
```

现在造“加一”（后继）和加法：

```text
SUCC := λn. λf. λx. f (n f x) ; 在 n 次基础上再多用一次 f
ADD := λm. λn. λf. λx. m f (n f x) ; m 次 + n 次
```

SUCC 的意思：n 表示“用 f 的 n 次”，SUCC n 就再用一次 f，所以是 n+1。ADD 把 m 次和 n 次首尾相接，总共 m+n 次。用 Racket 跑：

```racket
(define succ (λ (n) (λ (f) (λ (x) (f ((n f) x))))))
(define add (λ (m) (λ (n) (λ (f) (λ (x) ((m f) ((n f) x)))))))

(((succ c2) add1) 0)
;; 3 c2 加一 = c3

((((add c2) c3) add1) 0)
;; 5 2 + 3 = 5
```

**只用函数，我们构造了布尔选择器、自然数、后继和加法。** 这不是在“模拟”数字——Church 编码展示了如何以函数表示这些基本数据和运算；λ 演算的通用计算能力还依赖更完整的理论结果。

## α 转换，替换之前先改名

β 归约看起来直白，但藏着一个陷阱。看这个表达式：

```text
(λx. λy. x) y
```

按 β 归约，要把 `x` 替换成 `y`。如果你直接替换，会得到 `λy. y`——但这错了。外层那个自由的 `y`，被内层约束的 `y` 意外“捕获”了，原本不该被绑定的 `y` 被绑死了。

正确的做法是：替换之前，先把内部那个同名的约束变量改个名，避开冲突：

```text
(λx. λz. x) y → λz. y
```

把内层的 `y` 改成 `z`，再代入，结果才对。这种“改名”叫 α 转换（alpha conversion）。它背后的等价关系叫 α 等价：`λx. x` 和 `λy. y` 是同一个函数，变量叫什么名字不影响含义。

**安全的 β 归约需要避免变量捕获；有冲突时先进行 α 改名，再替换。**

![β 归约的参数替换过程与 α 改名避免变量捕获的示例](/images/racket-beta-reduction.svg) 这套机制叫避免捕获的替换（capture-avoiding substitution），也是实现任何 λ 演算解释器时最容易写错的地方。

## 亲手写一个 λ 演算解释器

把上面的理论写成 Racket，就是一个最小的解释器。先把三种表达式表示成数据结构：

```racket
#lang racket

(struct Var (name)) ; 变量
(struct Abs (param body)) ; 函数抽象：参数 + 函数体
(struct App (func arg)) ; 函数应用：函数 + 参数
```

核心是避免捕获的替换：只替换自由出现的变量；遇到可能捕获新表达式自由变量的绑定时，先用 gensym 生成全新的符号，再进行 α 改名。

```racket
(define (free-in? name expr)
  (match expr
    [(Var y) (eq? name y)]
    [(Abs p body)
     (and (not (eq? name p)) (free-in? name body))]
    [(App f a)
     (or (free-in? name f) (free-in? name a))]))

(define (subst expr x v)
  (match expr
    [(Var y) (if (eq? y x) v expr)]
    [(Abs p body)
     (cond
       [(eq? p x) expr]
       [(not (free-in? x body)) expr]
       [(free-in? p v)
        (define fresh (gensym p))
        (Abs fresh
             (subst (subst body p (Var fresh)) x v))]
       [else (Abs p (subst body x v))])]
    [(App f a)
     (App (subst f x v) (subst a x v))]))
```

这里约定 Var 的名字与 Abs 的参数都是符号。gensym 生成不与现有符号相同的新符号，即使打印名称相近，也不会误捕获变量。

接下来实现一次最左最外层 β 归约。没有可归约项时返回 #f，否则返回新语法树。为了寻找完整正规形，也会进入函数抽象内部。

```racket
(define (step expr)
  (match expr
    [(App (Abs p body) arg) (subst body p arg)]
    [(App f a)
     (cond [(step f) => (lambda (f*) (App f* a))]
           [(step a) => (lambda (a*) (App f a*))]
           [else #f])]
    [(Abs p body)
     (define next (step body))
     (and next (Abs p next))]
    [(Var _) #f]))

(define (normalize-term expr fuel)
  (unless (exact-nonnegative-integer? fuel)
    (raise-argument-error 'normalize-term
                          "exact-nonnegative-integer?" fuel))
  (let loop ([term expr] [remaining fuel])
    (define next (step term))
    (cond [(not next) term]
          [(zero? remaining)
           (error 'normalize-term "reduction budget exhausted")]
          [else (loop next (sub1 remaining))])))
```

归约预算限制允许的 β 归约次数，不是运行时间或内存上限。无类型 λ 演算可能不存在正规形，所以不能保证归约总能结束。这个实现也没有解析器，输入仍是手动构造的语法树。

将本节从 #lang racket 开始的结构定义与以上代码保存在同一文件，再追加测试：

```racket
(module+ test
  (require rackunit)
  (check-match
   (normalize-term (App (Abs 'x (Var 'x)) (Var 'a)) 10)
   (Var 'a))
  (define capture-example
    (normalize-term
     (App (Abs 'x (Abs 'y (Var 'x))) (Var 'y)) 10))
  (check-true (Abs? capture-example))
  (check-false (eq? (Abs-param capture-example) 'y))
  (check-true (free-in? 'y capture-example))
  (define omega-part (Abs 'x (App (Var 'x) (Var 'x))))
  (check-exn exn:fail?
             (lambda ()
               (normalize-term (App omega-part omega-part) 10))))
```

保存为 lambda-calculus.rkt，执行 `raco test lambda-calculus.rkt`，预期五项检查通过。测试关注结构与自由变量，而不依赖 gensym 产生的具体名字。最后一个测试验证无限自我应用不会被错误地认作正规形。

这已经是一个具有捕获避免替换、正规序归约与预算控制的教学归约器，而不是完整的 Racket 实现。下一章将通过不动点组合子继续讨论递归。

---

λ 演算还有一件事没解决：它没有变量定义，没有 `define`，没有 `let`。这意味着你没法给一个函数起名字，更没法让一个函数在函数体里调用自己。没有名字，递归从哪儿来？

Church 用一个绝妙的技巧回答了这个问题——一个叫 Y 组合子（Y-combinator）的函数，它能让任何函数“找到自己”。那是 λ 演算最烧脑也最漂亮的部分。下一篇就讲它：递归，到底从哪里来。
