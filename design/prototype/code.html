A · 定义块（默认态）

现行
racket复制
;; 三个高阶函数覆盖九成列表处理
(define squares
  (map (λ (x) (* x x)) (range 1 6)))   ;; '(1 4 9 16 25)
(define evens
  (filter even? (range 0 10)))        ;; '(0 2 4 6 8)
(define total
  (foldl + 0 squares))               ;; 55

输出注释惯例：结果写在 ;; 注释里，灰色斜体，与代码正文区分——沿用现行内容写法。

B · 复制成功态

推导
racket✓ 已复制
(foldl + 0 (map (λ (x) (* x x)) (range 1 6)))

反馈及时：点击复制后按钮变「✓ 已复制」（--ok 色），约 1.5s 后回落为「复制」，不弹遮挡式提示。

C · REPL 交互块
